Start the server

1

Go to the project folder.

cd Amina
2

Install dependencies, once (already done if node_modules/ exists).

npm install --legacy-peer-deps
3

Build the client and start the server. This serves the app and the API on the same port.

npm run build && npm start

For live-reload development instead, run npm run dev (same port, no build step).

4

Come back to this page and press Open App.

Honest note. Without GEMINI_API_KEY in a .env file, the app still opens, but the AI routes return truthful degraded fallbacks instead of real answers. The status line above also reports whether the server has a key.
