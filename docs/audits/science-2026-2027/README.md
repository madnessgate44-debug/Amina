# Grade 5 French Science Term 1 — source audit outputs

This branch contains durable, machine-readable audit outputs for the 2026–2027 Ministry-hosted Grade 5 French Science Term 1 student book.

- `library-comparison.json`: page-by-page normalized extracted-text comparison between the canonical Ministry-hosted PDF and the separately supplied Library PDF.
- `source-audit.json`: generated by the Ministry PDF audit workflow after its next successful run on `main` and published here.
- `ministry-page-fingerprints.csv`: per-PDF-page normalized extracted-text fingerprints generated by that workflow.

The original PDF and full extracted text are deliberately not committed. Fingerprint equivalence is not proof of visual identity, PDF byte identity, source authenticity, or pedagogical equivalence. The canonical PDF has 109 pages; the Library copy has 110 PDF pages, with the extra page outside the 109-page book content.
