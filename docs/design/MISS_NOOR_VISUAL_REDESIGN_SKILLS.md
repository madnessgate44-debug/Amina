This is the curated skill set for the full visual redesign. The objective is to give one accountable creative-director agent the combined capabilities of product design, UX, visual composition, frontend implementation, accessibility, and browser QA.

## 2. External GitHub skill collections reviewed

### A. Frontend Agent Skills — hueyexe
Source: https://github.com/hueyexe/frontend-agent-skills  
License: MIT

Selected capabilities:
- `ui-visual-composition`: hierarchy, spacing, typography, color, depth, imagery, polish.
- `design-systems-frontend-architecture`: tokens, component contracts, responsive systems, design governance.
- `ux-research-discovery-testing`: discovery, user goals, usability testing, evidence.
- `ux-usability-foundations`: mental models, cognitive load, learnability, feedback, error recovery.
- `information-architecture-navigation`: navigation, taxonomy, hierarchy, wayfinding.
- `interaction-patterns-components`: interaction patterns and reusable component behavior.
- `ux-writing-content-design`: concise labels, CTAs, onboarding, empty/error/success states.
- `accessibility-inclusive-design`: inclusive behavior, keyboard, screen readers, resilient layouts.

### B. React Frontend Skills — PyModel
Source: https://github.com/PyModel/react-frontend-skills

Selected capabilities:
- `ui-design`: UI/UX, accessibility, responsive design.
- `tailwind`: Tailwind CSS v4 patterns and theming.
- `web-design-guidelines`: interface review against web UI guidelines.
- `playwright`: browser automation and end-to-end verification.
- `react`: component architecture, hooks, rendering behavior.
- `vercel-react-best-practices`: React performance and implementation quality.

### C. Oh My Agent — first-fluke
Source: https://github.com/first-fluke/oh-my-agent

Selected capabilities:
- `oma-design`: structured product-interface review.
- `oma-frontend`: frontend execution workflow and implementation guardrails.
- `oma-qa`: evidence-led quality review.

Adapt only transferable design and QA practices. Its Next.js/shadcn defaults do not apply to this React + Vite app.

## 4. Assigned operating model

One accountable agent: **Miss Noor Creative Director**.

It combines:
1. Product/UX architecture
2. Visual design and art direction
3. Design-system engineering
4. React/Tailwind implementation
5. Accessibility and responsive design
6. Screenshot-led browser QA

The local project skills remain the app-specific source of truth. External collections are curated references, not a mandate to import unrelated frameworks or dependencies.
